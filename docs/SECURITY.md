# Security and safe stream proxy design

Secrets go in Vercel/Supabase environment configuration, never source control or the browser bundle. `.env.example` contains names only. All media/addon URL entry points accept HTTPS and reject embedded username/password. Provider access tokens may appear in query strings, so provider media URLs are not logged and IPTV URLs are stripped from persisted libraries. Browser requests omit credentials. Playlists and EPG are session-only. Artwork sources should be allowlisted/proxied before a broad public release.

There is deliberately no open proxy endpoint. For a provider that requires CORS assistance, deploy a separate streaming gateway only after explicit user authorization. Require a verified Supabase user JWT; resolve an owned provider record under RLS; keep its credentials envelope-encrypted using a managed KMS key. Browser sends opaque provider/channel IDs, never arbitrary target URLs. Provider hosts must be administratively allowlisted. Resolve and reject private, loopback, link-local, metadata and reserved IPv4/IPv6 addresses at every request and redirect; pin resolved destinations to resist DNS rebinding. Restrict ports and protocols; cap redirects, bytes, time, concurrency and bandwidth per account; support Range; validate content type. Rewrite each HLS child URI through the same checks and sign expiring route tokens. Strip cookies, incoming auth headers and upstream secrets. Never return credentials in errors or logs. Use isolated egress and external rate limiting. This gateway is an architecture, not an implemented open relay.

Authentication is delegated to Supabase with email verification, OAuth PKCE and session refresh. Apply migration RLS before enabling public use. Configure exact callback URLs, Google consent and production SMTP. Public YouTube search has a bounded query, timeout, cached upstream requests, generic upstream errors and a process-local limiter. Use shared edge limiting before public scale. Dependabot or equivalent and periodic dependency audits are recommended.

No vehicle safety mechanism is circumvented. The app cannot guarantee playback while moving; use only displays the vehicle permits for passenger video.
